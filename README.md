# TinkerHub CET — campus website redesign

A workshop-zine take on the official TinkerHub chapter at College of Engineering Trivandrum.

Keeps the mosaic palette (cyan, navy, yellow, coral, green) from the existing identity, then rebuilds the site around people, history, and play — not a brochure of activities.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

`vite.config.js` uses `base: './'` so the build can be dropped onto GitHub Pages.

## What is here

- Landing workbench with draggable stickers
- About, culture, events, Maker Kootam, history archive, crew lockers, member stories
- Mosaic memory mini-game
- Type `BEKIND` for a hidden workshop
